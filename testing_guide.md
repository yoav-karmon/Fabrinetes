# Fabrinetes Testing Guide

## Overview
This guide explains how to test the Fabrinetes Docker container management system, including using test configurations, managing containers, and verifying functionality.

## Testing Environment Setup

### Prerequisites
- Docker installed and running
- Fabrinetes repository cloned
- Terminal access

### Available Test Containers
- **fabrinetes-dev-testing**: Primary lightweight testing environment

## Basic Testing Workflow

### 0. Clean Up Before Testing (Recommended)
```bash
# Clean up any existing test containers
docker stop $(docker ps -q --filter ancestor=fabrinetes-dev-testing:latest) 2>/dev/null || true
docker rm $(docker ps -aq --filter ancestor=fabrinetes-dev-testing:latest) 2>/dev/null || true
```

### 1. Build Test Container (Only if Dockerfile Changed)
```bash
# Build the primary testing container (only needed when Dockerfile is modified)
./fabrinetes gen-image containers/fabrinetes-dev-testing/config.toml

# Verify build success
docker images | grep fabrinetes-dev-testing
```

### 2. Run Test Container
```bash
# Run without confirmation prompt
./fabrinetes run --file fabrinetes.config --name fabrinetes-dev-testing --no-ask

# Run with GUI support (if needed)
./fabrinetes run --file fabrinetes.config --name fabrinetes-dev-testing --x11 --no-ask

# Run with auto-cleanup
./fabrinetes run --file fabrinetes.config --name fabrinetes-dev-testing --rm --no-ask
```

### 3. Verify Container Status
```bash
# List running containers
./fabrinetes list

# Check container details
docker ps --filter name=fabrinetes-dev-testing
```

## Container Management Testing

### Starting Containers
```bash
# Start test container
./fabrinetes run --file fabrinetes.config --name fabrinetes-dev-testing --no-ask

# Start with different options
./fabrinetes run --file containers/fabrinetes-dev-testing/config/fabrinetes.config --name fabrinetes-dev-testing --rm --x11 --no-ask
```

### Executing Commands in Containers

#### Get the Actual Container Name
```bash
# Get the running container name (replace YYYYMMDD-HHMMSS with actual timestamp)
docker ps --filter ancestor=fabrinetes-dev-testing:latest --format "{{.Names}}"

# Example output: fabrinetes-dev-testing-20241008-143025
```

#### Run Commands in Container
```bash
# Run a simple command (use actual container name)
./fabrinetes exec --container-name fabrinetes-dev-testing-20241008-143025 --command 'echo "Hello from container"'

# Run interactive command
./fabrinetes exec --container-name fabrinetes-dev-testing-20241008-143025 --command 'pwd && ls -la' --interactive

# Check environment variables
./fabrinetes exec --container-name fabrinetes-dev-testing-20241008-143025 --command 'echo "PATH: $PATH"'
```

#### Container Name Format
- **Format**: `{repository-name}-{YYYYMMDD-HHMMSS}`
- **Example**: `fabrinetes-dev-testing-20241008-143025`
- **Generated by**: Fabrinetes automatically creates unique names with timestamps
- **Purpose**: Prevents container name conflicts when running multiple instances

### Opening Interactive Shell
```bash
# Get container name first
CONTAINER_NAME=$(docker ps --filter ancestor=fabrinetes-dev-testing:latest --format "{{.Names}}" | head -1)

# Open interactive shell in container
./fabrinetes shell --container-name $CONTAINER_NAME
```

## Container Cleanup Testing

### Clean Up Before Running (Important!)
```bash
# Stop any existing fabrinetes-dev-testing containers
docker stop $(docker ps -q --filter ancestor=fabrinetes-dev-testing:latest) 2>/dev/null || true

# Remove any existing fabrinetes-dev-testing containers
docker rm $(docker ps -aq --filter ancestor=fabrinetes-dev-testing:latest) 2>/dev/null || true

# Optional: Remove the image to force rebuild
docker rmi fabrinetes-dev-testing:latest 2>/dev/null || true
```

### Stop Running Containers
```bash
# Stop specific container
docker stop fabrinetes-dev-testing-YYYYMMDD-HHMMSS

# Stop all Fabrinetes containers
docker stop $(docker ps -q --filter ancestor=fabrinetes-dev-testing:latest)
```

### Remove Containers
```bash
# Remove stopped container
docker rm fabrinetes-dev-testing-YYYYMMDD-HHMMSS

# Remove all stopped Fabrinetes containers
docker container prune --filter ancestor=fabrinetes-dev-testing:latest
```

### Clean Up Images
```bash
# Remove specific image
docker rmi fabrinetes-dev-testing:latest

# Remove unused images
docker image prune -a
```

## Configuration Testing

### Test Individual Container Configs
```bash
# Test fabrinetes-dev-testing config (primary test container)
./fabrinetes run --file containers/fabrinetes-dev-testing/config/fabrinetes.config --name fabrinetes-dev-testing --no-ask

# Test other configs (for production environments)
./fabrinetes run --file containers/fabrinetes-dev/config/fabrinetes.config --name fabrinetes-dev --no-ask
./fabrinetes run --file containers/fabrinetes-fpga-full/config/fabrinetes.config --name fabrinetes-fpga-full --no-ask
```

### Verify Mount Points
```bash
# Check if mounts are working
./fabrinetes exec --container-name fabrinetes-dev-testing-YYYYMMDD-HHMMSS --command 'ls -la /root/repos'

# Verify environment initialization
./fabrinetes exec --container-name fabrinetes-dev-testing-YYYYMMDD-HHMMSS --command 'cat /etc/profile.d/init_env.sh'
```

## Automated Testing Script

### Create Test Script
```bash
#!/bin/bash
# test_fabrinetes.sh

echo "=== Fabrinetes Testing Script (fabrinetes-dev-testing) ==="

# Build test container (only if Dockerfile changed)
echo "Building test container (only if Dockerfile was modified)..."
./fabrinetes gen-image containers/fabrinetes-dev-testing/config.toml

# Run test container
echo "Running test container..."
./fabrinetes run --file fabrinetes.config --name fabrinetes-dev-testing --no-ask

# Get container name
CONTAINER_NAME=$(docker ps --filter ancestor=fabrinetes-dev-testing:latest --format "{{.Names}}" | head -1)
echo "Container name: $CONTAINER_NAME"

# Test basic functionality
echo "Testing basic commands..."
./fabrinetes exec --container-name $CONTAINER_NAME --command 'echo "Container is running"'
./fabrinetes exec --container-name $CONTAINER_NAME --command 'pwd && ls -la'

# Test PATH management
echo "Testing PATH management..."
./fabrinetes exec --container-name $CONTAINER_NAME --command 'cd /root/repos/Fabrinetes && source ~/.bashrc && echo "REPO_TOP: $REPO_TOP"'

# Cleanup
echo "Cleaning up..."
docker stop $CONTAINER_NAME
docker rm $CONTAINER_NAME

echo "=== Testing Complete ==="
```

## Troubleshooting

### Common Issues

#### Container Won't Start
```bash
# Check Docker daemon
docker info

# Check available space
df -h

# Check Docker logs
journalctl -u docker
```

#### Mount Issues
```bash
# Verify mount paths exist
ls -la $HOME/repo
ls -la containers/fabrinetes-dev-testing/Fabrinetes_init_env.sh

# Check mount permissions
ls -la containers/fabrinetes-dev-testing/
```

#### PATH Issues
```bash
# Check bashrc sourcing
./fabrinetes exec --container-name CONTAINER_NAME --command 'source ~/.bashrc && echo "PATH: $PATH"'

# Verify init_env.sh is mounted
./fabrinetes exec --container-name CONTAINER_NAME --command 'ls -la /etc/profile.d/init_env.sh'
```

## Best Practices

### Testing Workflow
1. **Always use `--no-ask`** for automated testing
2. **Clean up containers** after testing
3. **Use specific container names** for targeted testing
4. **Test both interactive and non-interactive modes**
5. **Verify all mount points** are working
6. **Check PATH management** in different repositories

### Container Naming
- Containers use timestamp-based names: `fabrinetes-dev-testing-YYYYMMDD-HHMMSS`
- Always get the exact container name before running exec/shell commands
- Use `docker ps` to find running container names

### Configuration Testing
- Test both master config and individual container configs
- Verify environment variables are properly expanded
- Check that all mounts are accessible inside containers

This testing guide ensures comprehensive validation of the Fabrinetes system functionality.
